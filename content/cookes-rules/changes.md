This file lists things that we remembered that we changed from Cooke's Rules.

1. Plugs for Roy Cook's other works removed.
2. Index removed.  We can't maintain this with Markdown, and if we're going to
   have an index, we're going to have the computer build it for us.  (We
   haven't yet figured out how.)
3. In seven-card stud, the double bet on fourth street for a paired door card
   has gone from a universal rule to almost unheard of.  (Much like stud.)
4. Cash does not play.
